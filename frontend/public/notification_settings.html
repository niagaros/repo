How these three tabs work together
Default / Fallback — where everything goes if no specific person is set up for it (your safety net). Categories — fine-tunes which channel this fallback uses per category. People — extra, named individuals layered on top of the fallback, for the specific categories they choose.
Default Delivery Channels
Where every alert for this account goes if no one on the People tab is scoped to catch it. Leave a field empty to skip that channel. Mandatory/critical events always go out regardless of the category toggles. Use "Test" to confirm a channel works.
⚠ While AWS SNS is in sandbox mode, SMS only reaches numbers explicitly verified in AWS — use "Test" to check this specific number.
